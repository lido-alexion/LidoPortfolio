# Portfolio Specification

| Field | Value |
|-------|-------|
| **Document** | Portfolio Specification (Holdings workspace) |
| **Version** | 1.0 |
| **Status** | Active (SD-031) |

## Purpose

Answer: **How should I manage my existing holdings?**

Route: `/holdings` (nav label **Portfolio**).

## Primary data

Current positions · allocation · returns · trailing stops · risk ·
recommendation status for owned stocks.

## Must not

- Stock discovery (use Discovery)
- Full market/portfolio dashboard (use Dashboard)
- Deep research tabs (use Watchlist)
