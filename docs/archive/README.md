# Archived Product Docs

This directory contains retired chronological specs, architecture notes, planning registers, and audits.

Use these files only for historical context, source archaeology, or decision lineage. Current product behaviour lives in [../current/](../current/).

## Archived Groups

- [specs/](./specs/) - original `specs/` tree, including architecture, governance, V3-V9 planning, registries, and legacy source-of-truth files.
- [v2/](./v2/) - V2 feature packs, policy decisions, boundaries, implementation matrices, and final reconciliation.
- [v2.1/](./v2.1/) - V2.1 shadow/current packs and product hardening audits.
- [audits/](./audits/) - historical feature coverage and deviation audits.

If an archived document conflicts with [../current/](../current/), prefer the current document and the running implementation.
