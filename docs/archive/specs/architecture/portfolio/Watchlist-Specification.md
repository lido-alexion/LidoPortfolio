# Watchlist Specification

| Field | Value |
|-------|-------|
| **Document** | Watchlist Specification |
| **Version** | 1.0 |
| **Status** | Active (SD-031) |

## Purpose

Answer: **Should I invest in this stock?**

Watchlist is the **stock research workspace**.

## Layout

- Left: watchlist membership
- Center: price chart
- Right / below: tabbed analytics

### Tabs

1. **Stock Analytics** — descriptive metrics (`StockAnalyticsService`)
2. **Evaluation Profile** — Evaluation Engine outputs
3. **Recommendation Preview** — active Strategy recommendation / preview

## Must not

- Portfolio-wide performance dashboards
- Discovery run management (link out to Discovery / Screeners)
