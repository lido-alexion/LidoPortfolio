# FEAT-052 functional test plan

**Implementation state:** IMPLEMENTED on StoX V8.  
**Functional testing state:** Open; record results per scenario below.  
**Owner:** Product functional testing, with an operator for controlled outage exercises.  
**Source of implementation evidence:** [FEAT-052 acceptance audit](../audit/V8-FEAT-052-ACCEPTANCE-AUDIT.md). The [frozen specification](../archive/specs/V8-StoX-OpenTelemetry-LidoTelemetry-Integration-Specification.md) remains the behavioral contract.

This plan carries the remaining end-to-end and operational checks into product functional testing. Existing bounded production probes establish implementation evidence, but do not count as passes for broader scenarios.
