# Release notes — 2026-06-21 (uncommitted batch)

Deploy after merging or uploading this working tree. **One new migration** — run `migrate` on production.

---

## Summary of changes

### Holdings UI
- Trailing-stop styling: red symbol, solid red Sell button when LTP &lt; trailing stop
- **Avg Buy** / **Invested** exclude fees; new **Fees** column (`total_fees` + % of invested)
- Default column order: Qty/Avg Buy after Highest Close; **Realized P/L** hidden by default

### Transactions UI
- Submit shows **Adding…** / **Updating…** while saving
- Calendar picker icon with date dots
- Qty defaults empty; after add, form keeps fields except **price** cleared
- **Notes** column in tables
- **Active transactions** only (open holdings); **Squared-off** page at `/transactions/closed` (paginated, edit/delete)
- Search by symbol/name on both tables

### API / backend
- `GET /transactions?scope=open|closed|all` (+ `search`, `page`, `per_page`)
- Transaction update/delete: scoped route binding (fixes false 403)
- Delete buy: dry-run ledger replay; blocks orphan sells with 422 message
- Polished API error toasts (`api.js`)
- Holdings recalc: fees excluded from cost basis; `total_fees` on holdings

| `2026_06_21_000001_add_total_fees_to_portfolio_holdings` | Adds `portfolio_holdings.total_fees`; **recalculates all users' holdings** |

## One-time on server: migration

**With SSH:**

```bash
cd /home/USER/public_html/lidoportfolio
php artisan migrate --force
php artisan config:cache
```

**Without SSH:**

1. Upload `deploy/cpanel-migrate.php` → `public_html/portfolio/cpanel-migrate.php` (set `SETUP_TOKEN`)
2. Visit `https://lidoalexion.com/portfolio/cpanel-migrate.php?token=YOUR_TOKEN`
3. Confirm output includes `2026_06_21_000001_add_total_fees_to_portfolio_holdings` … **DONE**
4. **Delete** `cpanel-migrate.php`

The migration adds `total_fees` and runs `HoldingsCalculationService::recalculateForUser()` for every user (safe to re-run only via migrate once; recalc is idempotent if run again from Holdings page).

## Rollback (if needed)

```bash
php artisan migrate:rollback --step=1 --force
```

Then redeploy previous `app/` + `build/` artifacts. Rollback drops `total_fees` column only; does not restore old fee-inclusive `invested_amount` values — run holdings recalc from a previous code version if you need that semantics back.
