E2E-35 — Read dated stock price history without sync authority

- Requires: An authenticated Investor and a known security.

- Warning: Price-history reads do not initiate a provider backfill or change the transaction ledger. Admin source repair is a separate governed action.

1. Open `/holdings/42/prices` for the security being reviewed. A failed read offers Retry price history; unavailable data must not appear fetched.

2. Inspect dated OHLCV rows, source, chart, All history from and Since Buy from. All means available instrument history; Since Buy means the current position episode.

3. Switch All/Since Buy. A confirmed range with no cached prices stays empty/unavailable instead of inventing zero-priced bars.

4. Switch back to inspect the available range. Investors cannot use Force sync historical prices; request source-coverage review from an administrator when needed.

**Expected result:** Dated research remains read-only, with ranges and source limitations disclosed.

E2E-36 — Recover index research and retain local comparison choices

- Requires: An authenticated Investor and available index master records.

- Warning: Missing benchmark history is not replaced with another index. Comparison selection is a Portfolio-scoped presentation preference, not a strategy or ledger change. VIX is excluded from relative-performance charts.

1. Open `/indices`. If overview/comparison reads fail, choose Retry index data.

2. Use the Broad market/Sector legend to select available relative-performance series; inspect the dated baseline. Selection affects presentation only.

3. Expand an index to inspect exchange, latest dated close, cached range, session count and change periods.

4. If history is unavailable, choose Retry index history. An authoritative empty response differs from a failed read.

5. If constituent lookup fails, choose Retry index constituents. Filter the returned names/symbols; a constituent link leads to Watchlist research.

6. Collapse/reopen as needed. Global sync remains an administrator source-coverage responsibility.

**Expected result:** Overview, history and constituent failures remain recoverable without treating absent evidence as usable prices or trading signals.

E2E-37 — Review dated market breadth with unavailable metrics disclosed

- Requires: An authenticated Investor and cached market-breadth snapshots.

- Warning: Cached market breadth is observational research, not a live execution quote. Investor UI must not instruct users to execute server backfill scripts.

1. Open `/market-depth`. An unavailable read offers Retry market breadth rather than claiming that no snapshots exist.

2. Review Date and the snapshot matrix. Choose percent or Count using Values; these are two views of the same observed evidence.

3. Choose another available date. Missing metrics display an unavailable dash in both modes, not an invented zero.

4. Inspect available history/series independently of the selected matrix date. If no snapshots are authoritatively returned, request administrator source-coverage review.

**Expected result:** Snapshot date, percentage/count meaning and absence remain explicit; no provider write or backfill is performed.

E2E-38 — Separate observational review from persisted report generation

- Requires: An owned Portfolio and permission to read/generate its review reports.

- Warning: Accepted recommendations are not executed transactions. A stored ReviewEngine snapshot is separate from the live Review dashboard; generating a new report must not rewrite old source/report evidence.

1. Open `/review`. Failed reads stop loading and offer recovery through Refresh; this observational path does not execute, cancel or reconcile an order.

2. Choose Reports to open stored report history. An unavailable list offers Retry rather than claiming no reports exist.

3. Open a report and inspect its immutable ID, period, generation/status, persisted metrics and methodology. An unavailable detail offers Retry review report; only an authoritative missing report is labelled not found.

4. Return to reports. Enter optional From/To and choose Generate deliberately. Failure retains the chosen period; retry creates/opens the separately identified report.

5. Verify the new report period and inspect methodology. Original report/source identity remains intact; browser fixtures do not qualify the actual ReviewEngine calculation.

**Expected result:** Read recovery and explicit new-report generation preserve historical evidence and the approval/execution distinction.

E2E-39 — Recover fundamental research and use educational pattern references

- Requires: An authenticated Investor and a resolvable security symbol.

- Warning: Fundamentals and patterns are research, not investment advice or permission to trade. Deterministic evidence and optional AI interpretation have separate sufficiency/freshness; an absent AI or insight payload does not erase valid evidence or invent a signal.

1. Open `/fundamentals/insights/TCS` for the intended security. Retry fundamental insights repeats ordinary symbol/evidence reads after a failed resolution or payload read.

2. Inspect the security identity, As of date, Freshness, deterministic evidence and any optional AI limitations. Missing insight content is disclosed separately.

3. Use Full fundamentals on Watchlist for deeper research. Refresh AI insights is an explicit optional interpretation action, not order execution.

4. Open `/patterns`, review the educational notice and select Chart patterns/Candlesticks. Filter names/characteristics and clear an unmatched filter to recover the reference list.

5. Reopen the guide to retain the local section choice. Pattern links identify a reference entry; they do not submit a recommendation or transaction.

**Expected result:** Symbol/source failures recover through reads, and research/educational choices remain separate from trading.
