Kite Holdings Onboarding

kite-holdings-onboarding · screen: /portfolio/kite-onboarding

Stage current Kite holdings, refine them with Console tradebooks, verify each stock, and commit selected stocks.

Overview

Kite holdings onboarding creates an editable, profile-scoped staging draft. It does not affect portfolio accounting until selected stocks are individually verified and committed. Kite opening dates are placeholders; replace them with evidence-based dates before verification. Review unresolved sells, cost-basis differences, corporate actions, transfers, and incomplete tradebook periods.

Practical tip: treat this page as one step in a larger workflow, not an isolated screen. Make one change at a time, verify the downstream effect, and use linked pages to complete the loop (for example: discovery → evaluation → recommendation → pending execution → review).

Controls

Fetch current Kite holdings
Capture the connected account holdings as the reference quantity and average cost for the draft.
Console tradebook upload
Upload CSV, TXT, XLSX, or Excel 2003 XML XLS files from Zerodha Console. Legacy binary XLS is unsupported; open it in Excel or LibreOffice and use Save As to create an XLSX copy. Upload one period at a time; formula and macro content is not executed.
Verify stock
Verify quantity, covered sells, and staged remaining cost for one stock. Verification does not commit it.
Commit verified stocks
Commit selected stocks after a fresh Kite recheck. Existing StoX transaction history blocks onboarding until it is reconciled.
Typical flow
Open this page, verify active portfolio context in the header, perform one meaningful action, then confirm the reflected change in list/cards/history before leaving.
Validation and errors
Form and API validations are shown as inline errors or toast messages. Fix the first reported issue, retry, and re-check dependent sections that consume the same data.

Concepts

Placeholder dates
A Kite opening date is not historical evidence. Replace it with a verified date before verification so it cannot distort historical performance.
Partial commit
Commit only the stocks that are ready. Other stocks remain in staging for later review.
Active portfolio context
Most data on this page is scoped by the selected portfolio profile; switching profile can completely change visible rows and metrics.
Data freshness
Many analytics depend on cached daily OHLCV and scheduled sync jobs. If numbers look stale, refresh this page and verify sync status in admin tools.
